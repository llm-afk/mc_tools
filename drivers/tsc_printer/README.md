# T-4502 PRO Windows 驱动

使用 TSC 官方 Generic 12.4.0，型号为 Bar Code Printer T-4502 PRO。来源和 SHA256 在上一级 packages.json 中，原始安装包保留数字签名及完整许可。

内部离线交付时保留 Generic_12.4.0.exe，软件优先使用随包驱动。驱动包内许可第 3.3 节限制未经许可的公开镜像分发。公开仓库首次使用时从官方获取、校验并缓存到本机用户数据目录，驱动安装包不提交到公开仓库。

软件检测已连接设备所需的驱动，在产测与调试释放设备后按需请求 Windows 管理员授权安装，再重新检查驱动、实体队列和 USB 端口。
