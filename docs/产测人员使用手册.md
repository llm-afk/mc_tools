# 电机产测软件 · 产测人员使用手册

## 01 · 每台电机怎样操作

日常生产只需：**接线 → 点击开始测试 → 等待自动完成 → 取下电机并贴好标签 → 拔下并更换下一台 → 再点开始测试**。

1. 按工装接线要求固定好电机，接好电源和 CAN 线。
2. 在“自动产测”页等候设备识别。确认当前来料正确，且画面提示可以开始。
3. 点击一次“开始测试”。点击前软件只做设备识别，不自动开始校准和产测。
4. 等待流程结束。运行时不要拔线、关闭电源或重复点击。
5. 看到本次完成提示后，核对打印出的标签与本件结果，再取下电机并贴标。
6. 拔下旧电机，等待软件识别其离开，再接下一台，重复上述操作。

界面尚未就绪时，“开始测试”会变灰，主提示写明当前缺少的设备或配置。按提示检查；不要通过反复点开始、重启或改产品参数来跳过问题。

中间的大字提示当前动作。识别到同一台电机且设备就绪后，屏幕才会提示点击开始。校准和加载测试期间电机可能转动，请勿触碰。只在出现本件通过提示后取下电机，核对标签上的正式 SN 再贴标。工位确认上一件断开后会提示接入下一台。

出现“打印结果未确认”时隔离本件并请负责人核对出纸，勿自行补打。提示“请先断开工装电源”时，按现场规程断电并确认电机和负载停稳后再取件。

首次启用工位或插入新设备时，软件会自动检查所需驱动。看到“正在准备设备驱动”请等候；Windows 请求管理员授权时请现场负责人允许。程序会核对真实型号和端口，安装完成后重新识别，不打印测试标签，也不会改动已正常工作的驱动。测试或电机调试正在运行时，驱动安装会等待设备任务结束。

如果授权被取消、驱动下载失败或安装后仍不正常，本次不会反复弹出授权窗口。请工程人员查看“打开日志目录”中的工位日志，必要时停止并关闭上位机，再运行软件根目录 install_drivers.cmd 重试。USB 能看到打印机、HTTP 打印服务正常，都不代表 Windows 已装好该型号打印驱动和打印队列。

## 02 · 界面上每一块表示什么

顶部菜单依次为“自动产测”“电机调试”“工位配置”“Help”。Help 可以在工作期间查看，不会中断测试；按 F1 也可打开。本手册在软件内离线可用。

**自动产测**：供产线人员日常使用。上方五项显示设备连接，中间的生产进度列出本件全部工序，下方是实时日志和报告上传数量。软件版本号在标题栏与右下角。

**电机调试**：供调试、维护人员查看位置、速度、扭矩反馈及控制电机；操作可能让电机动作。

**工位配置**：设置设备、产品 / SN、服务接口和维护工具。日常工人无需逐件进入修改，现场负责人配置一次并保存后会记忆。

“生产进度”显示每道工序的状态。日志中带有“[测量]”的行显示本件的测量结论和数值，完整曲线可在测试报告中查看。底部“报告上传”显示后台上传状态。

底部“打开日志目录”和“打开报告目录”打开对应文件夹，自己选择所需文件。页面日志显示近期摘要，后台文件保存更详细的过程、错误和通信记录。设备说明与操作提示使用固定高度，较长说明在固定区域显示，完整内容见日志。增大窗口高度时，多出的空间分给日志。

主页面日志从启动时就记录带毫秒时间的检查过程：配置 / 数据目录、工位产品与固件、组件加载、CANable 和串口枚举、五项硬件状态、打印服务启动、报告队列恢复及网络变化。黄色表示需注意，红色表示错误；查看旧日志时新消息不会强行把画面拉到底部，滚回底部后继续跟随。相同状态不重复刷屏，完整证据仍写入后台文件。

网络检查读取本机 Wi-Fi / 有线接口的连接状态、IP、网关和 DNS，不修改网络设置，也不通过启动检查申请 SN、打印或提交云端报告。“链路已连接”不代表 MES / OSS 可用或鉴权成功，要分别看实际业务回执。

## 03 · 第一次在这台电脑使用

1. 完整 clone 仓库或解压整个 pmt 文件夹，双击根目录“电机产测软件.exe”。保留其中的 services、drivers 和 firmware 等目录。
2. 请现场负责人确认 CANable、串口设备、实体打印机的 Windows 驱动已安装。根目录有 install_drivers.cmd，打印机仍需本型号驱动及实体打印队列。
3. 进入“工位配置 → 工位设备”：选择 CANable 与电源、测功机串口，并确认 EXE 旁 firmware 文件夹已放入当前工位的 APP 固件。
4. 进入“产品 / SN”：确认项目、物料、子分类、工厂、硬件 ABCD 和生产日期。
5. 进入“服务接口”：核对 SN 取号、打印、报告上报和 OSS 存储的地址及凭据。
6. 点击“保存并关闭”。修改保存成功后生效，下一次启动会沿用。
7. 先检查打印服务，再试打一张测试标签，核对纸张、排版和扫码结果。
8. 由现场负责人安排首件完整联调，分别确认校准、两项测试、取号写入、打印、本地报告和云端回执，然后投入批量生产。

新工位默认使用串口 auto；项目 C2、物料 KNEE、子分类 0STD、工厂 XC、硬件 0221；日期自动当天；每台打印 1 份。默认值需要与实际产品核对，不能直接作为产品身份的证明。

取号 API Key、报告 API Key、OSS AccessKey ID、OSS AccessKey Secret 默认为空，由负责服务的同事提供。“有默认网址”表示已给出目标地址，不代表鉴权通过或正式链路已验收。

## 04 · 设备状态怎样看

**CAN 适配器**：显示实际枚举到并选中的 CANable。只有一只时自动选择；多只时在“工位配置 → 工位设备”的 CANable SN 列表中选择正确的一只。列表实时刷新，拔下后会更新；不要同时用其他软件占用同一只适配器。

**待测电机**：显示发现的实际节点。来料优先探测 ID 1；完整产测开始后会按“产品 / SN”的物料分类设置目标 ID，并读回核对。单纯 USB 接好，不等于电机电源、CAN 接线或电机应答正常。

**测功机**：需要收到有效反馈，只有 COM 口出现还不够。检查传感器、串口连接与供电。多只设备不能唯一识别时，由负责人指定 COM 口。

**电源**：指给加载装置使用的可编程电源，不能代替电机本身的供电检查。“已连接、输出关闭”可以是正常待机状态。自动探测先确认测功机，避免向未知串口误发电源指令，因此“等待测功机识别”应先查测功机。

**标签打印机**：指本机打印服务确认指定打印队列可用。实体 USB、Windows 驱动 / 队列和本机服务都要正常。缺纸、开盖、离线等状态，按具体提示检查；某些驱动不能报告全部实体状态，仍需查看打印机面板和纸张。

“检测中”表示尚在识别；“未连接”或错误表示未满足当前条件；流程运行时设备可能显示由本次测试占用。等状态稳定后再开始，不要仅凭某一个绿色状态判断整套工装都可用。

## 05 · 自动产测会做哪些步骤

每件点击开始后，软件依次执行以下 11 步，并记录本次配置和工件标识：

1. **检查 APP 版本 / 按需 OTA**：读取当前版本，与 firmware 目录中数字版本最高的 APP 比较；版本较低才升级，重启后核对身份和版本。
2. **设置工位 ID / 重连核对**：按本件的物料分类设置目标 ID，并核对电机身份。
3. **写临时 SN / 重连核对**：使用本工位硬件 ABCD，其他位置填字符 0，写入后重连读回。
4. **自动校准**：发送校准指令并等待协议要求的完成结果。
5. **扭矩输出误差测试**：自动控制扭矩、加载和采集，生成 KT 数据并判断输出误差。
6. **电机特性曲线测试**：自动加载，记录速度、扭矩和功率等特性。
7. **MES 申请正式 SN**：使用工位产品参数和本次请求标识向取号服务申请。
8. **写正式 SN / 重连核对**：将正式号写入本件电机，再读回确认。
9. **标签打印**：向指定打印机提交本件正式 SN 标签。
10. **生成报告**：保存报告图片、两项 CSV 和流程记录。
11. **提交报告上传队列**：把本件交给本地持久队列，后续由后台继续上传。

软件会在各阶段核对身份、保存步骤状态，异常时停止后续步骤并尝试停机。测试未完成或不通过时，不应继续申请正式标签作为合格件使用。

当前 KT 输出误差按最大目标扭矩归一化，初版标准为不超过 5% 满量程；T-N 展示特性并检查流程 / 数据完整性，不等于已设置了转速、功率等全部量产门限。产品验收标准由负责人按当前型号确认。

步骤中的“完成”表示对应软件阶段已得到所需结果；最后提交队列不等于云端已经收到报告。云端状态另见“报告和云端上传”。

## 06 · 工位产品、临时 SN 与正式 SN

产品信息统一在“工位配置 → 产品 / SN”设置。一个工位长期生产同一型号时，配置一次后无需逐件更改。

产测目标 ID 随物料分类自动确定。髋关节（HIPX、HIPY）使用 ID 2，膝关节（KNEE）使用 ID 3，同一关节的左右子分类共用对应 ID。侧摆规定使用 ID 1，其 MES 物料代码尚待确认。其他分类可以保存，工位会在开测前提示该分类的目标 ID 尚未定义。

正式 SN 由项目 2 位、物料分类 4 位、子分类 4 位、工厂 2 位、硬件 ABCD 4 位、日期 6 位和 MES 分配的流水号 4 位组成，共 26 位。下拉框提供常用选项，也可以直接输入当前需要的字段；输入框限制长度。可选组合参考《模组SN获取与标签打印对接文档（工装侧）》V1.0 附录 A。例如 C2 的 KNEE 对应 0STD 或 0PRO，A2 的 KNEE 对应 LFRR 或 LRRF。工厂代号 JS 为镜识、GF 为赣锋、XC 为宣城。现场请按本批产品和生产工厂选择。

硬件段四位的含义：A 为结构版本，B 为芯片平台，C 为电机类型，D 为硬件版本。A、D 直接输入单个数字；B、C 可选择常用说明或直接输入代码。版本 1 就填 1，无需在文本框中写“硬件版本 1”。

当前芯片平台 B：1 为 GD，2 为 ADM。电机类型 C：1 C2_jieke、2 C2_xinzhi、3 C2_PRO_jieke、4 C2_PRO_xinzhi、5 A2_jieke、6 A2_xinzhi。下拉选项是便捷提示，实际型号及其测量参数要与现场产品一致。

临时 SN 共用同一个硬件段，格式为：**12 个字符 0 + ABCD + 10 个字符 0**。例如硬件 0221 对应 00000000000002210000000000。其他产品字段不会写入临时 SN，也不用额外配置一套临时号规则。

生产日期选“自动当天”或留空时，按本件流程锁定日期；若填写固定日期，后续工件会继续使用该值，换批次时由负责人核对。正式流水号由 MES 提供，不能自行编造或把临时 SN 当作正式号。

## 07 · APP 固件怎样更换

维护人员将当前工位使用的 APP `.bin` 文件直接放进 `电机产测软件.exe` 旁的 `firmware` 文件夹即可。目录保持一层，通常只留一个 APP，不需要导入、选择版本或管理 BOOT。

文件名最后的数字是十进制版本，例如 `ADM32F036_mc_app_released_fw_245.bin` 表示版本 245。文件名其余部分可以保留原发布名称。如果临时放了多个版本，软件取数字最大的文件；最高版本重名时会提示清理重复文件。

工位配置中的“APP 固件”自动显示当前文件和目标版本，“打开固件目录”可直接打开该文件夹。换文件后自动刷新，不需要重装上位机。旧的工位导入索引和自定义固件目录不再参与选择。正式程序文件按发布指纹校验，APP 作为现场可替换文件单独检查；更换合法 APP 不会被当作程序损坏。

每次点击开始后，软件先核对 APP 文件、来料身份和平台，再读取电机版本。电机版本低于文件版本时执行 APP OTA，相同或更高时直接继续，不自动降级。升级后重新连接并读回相同 SN 和目标版本，确认成功才继续产测。

软件保留布局、CRC 和可读取包内版本校验。单次传输使用已读入的完整镜像，避免换文件时混入不同版本；升级失败或结果不明确时停止本次流程并保存日志，不自动重刷。BOOT 由独立烧录工装维护。

## 08 · 标签打印怎样检查

当前默认链路：**上位机 → 随软件启动的本机 HTTP 打印服务 → Windows 打印队列 / 驱动 → USB 打印机**。USB001 是 Windows 打印端口，不是服务地址，也不是队列名称。

工位配置位置：“服务接口 → 标签打印”。常用默认值：服务地址 http://127.0.0.1:9876，状态路径 /api/status，打印路径 /api/print，队列 Bar Code Printer T-4502 PRO，每台 1 份。队列名称须与 Windows 中显示的完整名称一致。

**检查打印服务**：查询服务和所选打印机状态，不提交标签，不消耗正式 SN。

**试打测试标签**：实际提交 TEST-SN-0001 一张，不申请正式 SN。适合装机、换纸、调整排版后检查；测试纸不能贴到合格品上。

**标签纸 / 打印配置**：打开本机打印配置，供维护人员调整纸张和打印参数。当前常用规格为 50 × 15 mm、203 dpi、间距 3 mm；以现场实际纸张、打印头和碳带 / 热敏模式为准。保存此文件后重启上位机使服务重新加载。

打印机连不上时依次查看：实体设备已开机并连接 → Windows 出现正确实体队列 / 驱动 → 队列名称正确 → 本机服务状态 → 打印机面板和纸张状态。Microsoft Print to PDF 等虚拟队列不能替代实体标签机。

接口返回成功表示打印任务提交成功，**不能代替现场确认纸张已出、内容正确及条码可扫描**。

“打印结果未知”可能是请求已送出但回执丢失。软件不会自动补打一张以免重复。工人先保留本件和现场标签，交负责人核对 Windows 队列、打印机、SN 与日志；不要连续点试打、重开流程或重新申请另一个正式号。

如果使用远程打印服务，由负责人配置相应地址和目标设备；本机 USB 连接不会自动变成远程网络打印。

## 09 · 报告和云端上传

本地报告和云端上报是两个独立结果：**本件测试 / 报告完成**表示数据已在本机可靠保存并交给队列；**云端完成**要收到对应服务的成功回执。

后台顺序是先把报告图片和两份 CSV 上传到阿里云 OSS，再向 MES 登记对象信息。只收到 HTTP 200、只成功上传某个文件或只看到网络已连接，都不能替代最终报告登记成功。

底部“报告上传”分别显示待传、需处理和已完成数量。网络暂时失败会保留待传记录并后台重试；正常退出软件后，下次启动继续处理。认证、目标服务或记录问题会显示需处理，负责人根据日志修复。

打开“打开报告目录”可查看 report.png、kt_curve.csv、curve.csv 等报告材料。工作流、请求标识、文件指纹和上传回执还保存在工位数据 / 状态目录中；**不要只搬图片就认为已经保留了全部补传信息**。

服务配置位于“工位配置 → 服务接口”：
- SN 取号：MES 基础地址、取号路径、请求头名称、取号 API Key、后备环境变量名。已填写的 Key 优先。Key 留空时，软件读取指定的 Windows 环境变量，默认名为 MIRRORME_MES_API_KEY。变量名也留空可关闭后备读取。切换变量名后保存即可；若在 Windows 中新增或修改了变量值，请重新启动软件。
- 报告上报：报告接口完整地址、请求头名称、报告 API Key。完整地址包括域名和接口路径，例如 /mes-api/open-api/test-report，点击“保存并关闭”时会检查格式。
- OSS 存储：Endpoint、Bucket、Region、对象前缀、AccessKey ID / Secret。

取号 Key 和报告 Key 是独立配置，不默认相同。打印服务本身不需要这些云端 Key。缺取号 Key 时完整产测不能开始；缺报告 / OSS 凭据时本地报告会保留等待处理，不会因此变成云端成功。

已有待传任务绑定本件原来的 MES 和 OSS 目标；修改新任务的地址不会自动迁移旧任务。不要为补传手工改写回执、文件、哈希或队列状态，应让负责人按诊断信息处理。

## 10 · 异常怎样处理

软件会尽量自动停止后续工序、尝试失能电机和关闭加载电源，并保存异常记录。工人无需在失败后选择一串恢复操作；按主提示处理实物，由负责人查看日志。

**提示设备未连接 / 未就绪**：查看五项设备卡片中的具体原因，再检查对应供电、接线或服务。不要擅自更换本工位产品信息来让按钮变亮。

**测试失败 / 流程异常**：本件与合格件分开，记录时间和界面提示，保留标签及工件。确认停机状态后按现场流程换件，异常不会自动变成通过。

**失能、停机或校准停止未确认**：先按现场规程断开工装电源，再拆卸和处理；不能只看上位机画面就认定机械端已经安全停止。

**校准状态无法确认**：软件只按固件现有应答判断。某些固件状态不能证明一次新校准已结束时，必须交研发 / 维护人员核对协议和日志，不能重复清错或连续校准来强行通过。

**打印结果未知**：按“标签打印怎样检查”核对现场是否已出纸，禁止盲目补打。

**报告保存失败 / 磁盘空间不足**：保留电机与本次记录，由负责人处理磁盘、权限或被占用文件。未可靠保存不能当作正常完成，也不要直接删除状态目录。

**云端待传 / 需处理**：本地测量结果与上传状态分别核对，由负责人修复网络、Key 或目标服务。不要因此重测同一件或再申请 SN。

“工位配置 → 管理”的“工程恢复未完成记录”“工程归档异常记录”用于工程人员核对和补处理。归档保留证据，不是删除失败或把失败变合格；结果不明的写入、升级和打印不会盲目重放。

需要求助时，优先导出本次启动日志，提供软件版本、发生时间、工序、SN / 工件标识、完整提示、当时做了什么及实物状态。不要只发送“连接不上”或截掉错误细节。

## 11 · 日志、报告与现场反馈

“打开日志目录”打开日志文件夹。每次识别并建立电机连接就创建一份新的连接日志，即使未点击开始也会记录探测过程；同一连接下的校准、测试、打印等使用同一关联信息。

短暂探测丢包或预期重启不会立即拆成另一份日志。持续离开约 2 秒后结束该连接，再连接下一件时创建新日志。一天的 station 日志还记录软件启动、配置、后台服务和全局异常等事件。

连接日志通常为 motor-日期时间-连接标识.log；工位日志为 station-日期.log。按故障时间查找，并结合会话 / 请求标识追踪。后台记录的内容比主界面摘要完整，可包含阶段耗时、协议索引、版本前后值、通信计数、服务响应和异常堆栈。

日志默认保留 30 天，后台定期清理过期日志，正在写的日志会保留。发生问题后应及时导出，不要等到超过保留期限。报告及相关工件记录不自动按 30 天删除，维护人员需要管理磁盘空间。

最方便的反馈方式：进入“工位配置 → 管理”，点击“导出本次启动日志”，选择 ZIP 保存位置；将它和必要的报告交给研发人员。该包包含本次启动诊断摘要和相关日志。“复制诊断信息”适合先提供版本、设备和服务配置摘要，密钥内容会脱敏。

默认配置和数据目录：%LOCALAPPDATA%\MirrorMe\FactoryStation。里面包括 station.json、logs、data、固件库和本机打印服务配置等。以界面的目录按钮及导出摘要中实际路径为准，避免找错 Windows 用户。

不要编辑或删除正在使用的日志、工件状态、待传请求或上传回执来“修复”问题。需要迁移现场记录时由负责人整体备份工位数据目录。

## 12 · 电机调试页怎样使用

电机调试供研发 / 维护人员使用，产线日常生产留在“自动产测”。切换页面时软件会异步停止当前模式并释放设备，再进入新模式；不要同时开第二个上位机争用 CANable。

进入调试页会自动探测并连接，电机 ID 更新为实际连接节点。连接后后台以 1 kHz 为目标进行状态通信，显示位置、速度、扭矩和温度等；未使能时采用监视命令，连接成功不会自动使能电机。实际频率受 Windows、USB 和反馈影响，不保证硬实时。

蓝线表示实际反馈，橙线表示目标。横轴单位 s，选择 5 / 10 / 30 秒显示窗口，刻度表示当前可见窗口内的相对时间，波形滚动。位置单位 rad，速度 rad/s；调试页扭矩采用协议单位，不能与测功机报告的 Nm 混为一谈。固件版本以十进制显示。

参数输入框和滑块就是实时待发送目标，支持鼠标滚轮；位置步进 0.1 rad。确认工装、目标值及工作区域后，维护人员才可点击“使能电机”。**使能后修改目标会直接参与后续发送，不再另点下发按钮。**

“停止电机”用于失能，之后仍可继续获取状态。“暂停显示”只暂停画面，不停止通信或电机；需要停止动作时用停止电机并确认反馈。停机和退出仍要按现场机械、电源规程操作。

“错误清除”“标零”“编码器校准”是实际设备指令，可能改变设备状态或参数，按按钮可用状态及现场流程使用。“清除波形”只清空画面缓存。

“保存显示数据”保存显示采样的 CSV，不是逐条 1 kHz 原始总线记录，不能仅靠它断言没有丢帧。波形绘图与通信分别运行，视觉刷新频率也不等于 CAN 发送频率。

调试时仍可打开“工位配置”；保存变更会先停止并释放调试连接，再按新配置重连。切回产测后重新等待设备就绪，由工人点击开始，不会因为调试页曾使能而自动开始生产。

## 13 · 保存配置、升级与结束工作

工位设置点击“保存并关闭”后记忆。下次运行继续使用已保存的地址、产品信息和串口，目标 ID 由已保存的物料分类确定；软件升级不应把现场选项重置为默认。

API Key 和 OSS 凭据以 Windows 当前用户保护的密文保存，不在手册或软件包中预置生产密钥。同一电脑和同一用户不用每次重填；换电脑或换 Windows 用户，需要重新录入凭据。不要把密文文件当作通用明文 Key 复制使用。

更换软件时先等当前流程结束并正常关闭，再完整替换项目目录。现场运行入口始终是根目录“电机产测软件.exe”；交付时可压缩整个 pmt 文件夹，目标电脑完整解压。当前电脑工位配置与现场数据在用户目录，搬软件文件夹不会自动迁移这些现场记录。

更换固件直接替换 EXE 旁 firmware 文件夹中的 APP；交付时连同该文件夹一起压缩。不同平台或型号的工位放入各自对应的发布固件。

需要更新软件时，先正常关闭上位机，由负责人在 pmt 文件夹执行 git pull --ff-only，再重新启动并核对版本。更新继续使用本机保存的工位配置、密钥、日志和报告。

下班前等当前工件处理完成，核对是否有“需处理”报告或异常件。正常关闭一次，等软件完成停机、释放设备、保存状态并退出；不要在“正在停止 / 等待保存”时连续强关。未上传报告会在下次启动继续。

若退出提示失能或释放未确认，先按现场规程断开工装电源并交负责人处理。发生问题后保留原始记录，再导出诊断包。

诊断信息复制会包含当前 APP 版本和指纹、设备最近状态，以及最近一次异常的时间、工件 SN、工序、错误编号、传输上下文、收尾结果和日志路径。最近异常会标明对应工件，避免与当前接入电机混淆；密钥内容仍脱敏。
