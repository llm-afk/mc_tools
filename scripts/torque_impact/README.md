# 转子与转子架粘接可靠性冲击测试

运行：`python -m scripts.torque_impact --id 1 --serial <SN> --torque 30`

电源给阻尼器24V、3A，等待0.5秒。
第一次正、反测量各用50ms线性斜坡升至目标，再保持100ms，每次后休息900ms。
额外休息1秒，然后执行5组：正扭矩100ms、零900ms、负扭矩100ms、零900ms。
第5组完成后失能并关闭电源，不再复测或额外等待。

唯一合格判据：5组共10次冲击的末段扭矩幅值，分别除以第一次同方向
初始扭矩幅值，全部≥90%为绿色PASS，任一低于90%为红色FAIL。
末段取原始测功机中位数，优先30ms稳定窗口，其次20/15ms；否则选波动最小窗口。
波动不另作合格门槛。无法计算保持率、设备故障、采集失败或用户中止只报异常。
运行中的通信和过温停机保护保留，只决定实验能否完成，不参与粘接合格判定。

输出本目录data/<时间>/process.csv和result.json。CSV七列维持现有字段。
全部电机帧保留，测功机按主机接收时间一对一匹配，每帧最多使用一次，批次内保序。
多余测功机帧舍弃，20ms内没有可用帧则留空，不复制旧值。不同真实帧的相同数值保留。
主机接收时间不是硬件同步时间。判定始终使用导出前的原始样本。
result.json记录初始扭矩、每次冲击的窗口和保持率、最小保持率及运行参数。
