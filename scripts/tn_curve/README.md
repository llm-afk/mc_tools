# T-N 曲线测试

在 `scripts/tn_curve/app.py` 顶部配置电压、加载电流步进、上限、启停时间和温度限制。最大前馈扭矩默认使用 `TORQUE_FF`，可用 `--torque 20` 覆盖，支持负值，拒绝零和非有限值；覆盖只作用于本次运行，不修改默认配置。电源给磁粉阻尼器供电，被测电机由独立电池供电。

运行：`python -m scripts.tn_curve --id 1 --serial <SN>`。`python -m motor_platform --list` 查看适配器 SN；未传 --serial 时使用脚本顶部 SN，不自动切换 CANable。电源和测功机串口默认自动探测，多设备时在顶部指定端口。输入 quit、stop 或 Ctrl+C 正常结束。

流程：阻尼电流限值归零 → 前馈扭矩用 TORQUE_RAMP_S（默认 1 秒）线性升到目标 → 保持 TORQUE_SETTLE_S（默认 1 秒） → 开始曲线记录并逐步加载。平均每步增加 0.028125 A，目标 15 Hz，约 2.37 秒增加 1 A，比此前 0.01875 A/步快 50%。电源设置分辨率为 1 mA，按累计步数计算目标后量化，实际步进为 28/29 mA，避免舍入误差累积。周期包含设置和读回耗时；慢事务会降低实际频率，不补发积压步进。电源频率独立于 MOTOR_HZ。电机反馈速度绝对值连续 100 ms 小于 0.5 rad/s 时结束曲线采集；达到电流上限保持指定时间仍未堵转也结束并注明原因。

正常结束（包括 quit/stop/Ctrl+C、堵转、测试时限或电流上限）保持现有阻尼，用 STOP_TORQUE_RAMP_S（默认 1 秒）将电机扭矩线性降为零，再确认电机失能并直接关闭电源输出，不再分步卸载电流。故障退出不执行延时斜坡，直接尝试失能和关闭电源；未确认关闭会报告错误。

每次运行只生成 `data/时间/curve.csv`，不再生成 raw、诊断或摘要文件。运行结果和行数显示在终端。

停机后计算 `motor_speed_smooth_rad_s`、`motor_torque_smooth`、`dyno_speed_smooth_rad_s`、`dyno_torque_smooth_nm`，再按电机时间一对一匹配测功机帧。最终统一使用 `time_ms`，共十二列；全部电机帧保留，多余测功机帧舍弃，一帧最多使用一次，20ms内无可用帧则留空。四个 `*_SMOOTH_S` 配置平滑窗口，默认均为0.30秒。平滑先在各自完整采样上计算，再随原始值一起匹配。

为减少处理时间，先按最多 5 ms（不超过平滑窗口的 1/30）进行中位数聚合，再拟合并将平滑估计映射回原始时间点。此聚合只用于派生的平滑列，不删减原始采样点；同一批实测 3000 点两列处理约从 4.7 秒降至 0.19 秒，结果会与逐点拟合略有差异。

平滑采用按真实时间加权的鲁棒局部线性拟合，以中位数初始化、残差重加权抑制孤立毛刺，并限制拟合值不超出窗口内有效数据范围。正负方向不变换，不强制单调、不向目标指令靠拢；超过反馈超时的采样间隔分段处理。该方法参考 LOWESS 的局部线性与鲁棒重加权思路（https://www.statsmodels.org/stable/generated/statsmodels.nonparametric.smoothers_lowess.lowess.html），使用固定时间窗口，不增加库依赖。双侧离线处理避免单向滤波的固定延迟，但不是物理模型重建，仍可能平滑真实快速变化；不能区分所有机械振动与测量噪声，原始数据始终保留。控制、保护和堵转判断不使用平滑值。

绘图统一使用 `time_ms`。电机部分为速度、扭矩、双温度及速度/扭矩平滑；测功机部分为扭矩、速度、功率及速度/扭矩平滑。同一行表示时间邻近的两路接收帧，不等于硬件同步采样；不做前值填充或插值。

记录范围从升至最大扭矩后保持1秒、开始加载时算起，到第一条满足堵转判据的电机反馈时间（包含该帧）为止。超过该截止时间、启动和停机阶段不写入文件。最终CSV行数等于电机帧数，终端采集计数仍为两路实际帧数之和。

电源加载操作独立于电机控制循环，一次只执行一个设置加读回事务。关闭输出前等当前事务结束，保证串口顺序。测功机单位缩放仍需动态实测核对。15 Hz 设置加读回已单独在磁粉阻尼器小电流范围验证；本次脚本计时调整经过离线测试，未运行新的整套加载实验。
